# Changelog

All notable project changes are documented here.

## 1.0.0 - 2026-08-06

- rebuilt TradeVault as a private local-first trading journal;
- added performance, drawdown, expectancy, discipline, and setup analytics;
- added structured trade capture, journal search and filters, editing, and deletion;
- added a trading playbook and execution-quality fields;
- added IndexedDB persistence and optional AES-256-GCM vault encryption;
- added validated JSON and spreadsheet-safe CSV portability;
- added PWA support and hardened Docker deployment;
- added unit, browser, mobile, accessibility, CI, and security checks;
- added complete open-source project documentation and governance.
